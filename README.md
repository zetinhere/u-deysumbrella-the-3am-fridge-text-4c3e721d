A program that writes the one line a smart fridge would text its owner at 3am.

## The line

> It's 3am. The leftovers you swore you'd eat on Monday are now a science project. I'm not mad. I'm cold.

103 characters, one line. The payoff is a fridge pun with two meanings at once — "I'm not mad. I'm cold." is both an emotional shrug and a literal temperature report — and the angle (leftovers that became a science project) is fresh: no milk, no ice, no door left open.

## Run it

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`), mode 0644, byte-for-byte identical on every run. No network, no input.
